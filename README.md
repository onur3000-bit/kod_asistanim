# Kod-Asistan (v0.1)

Bu depo, Kod-Asistan projesinin tasarım belgelerini, akış şemalarını ve sürüm notlarını güvenli bir şekilde saklamak amacıyla oluşturulmuş dijital proje alanıdır.

## Proje Hakkında
Yazılım geliştirme sürecinde projelerin güncellenmesi ve sürüm kazanması temel bir süreçtir. Bu çalışma kapsamında projenin belgelendirilmesi, sürüm kontrol mantığının kavranması ve standartlara uygun bir depo yapısının kurulması hedeflenmiştir.

## v0.1 Sürüm Notları
* Proje deposu GitHub üzerinde yapılandırıldı.
* Dijital proje vitrini (README.md) Markdown formatında hazırlandı.
* Proje belgelerinin ve dosya yapısının temel iskeleti oluşturuldu.
